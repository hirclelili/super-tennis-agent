# Super Tennis Agent

广州 Super 超级网球俱乐部专属宣发运营 Agent。

这个新版本从旧的视频生成器中拆出来，主线改成固定服务一个网球场：

- 维护球场基础档案
- 根据运营阶段和目标生成宣发内容包
- 输出小红书、抖音/视频号、朋友圈、微信群、私聊回复
- 在需要时生成短视频脚本和拍摄清单

旧项目已移动到 `legacy-video-creator/`，后续可从里面复用视频脚本、素材识别和成片能力。

## 本地运行

```bash
npm run dev
```

打开：

```text
http://localhost:5173
```

## 当前版本

- **一周计划**：两次 AI 调用——先 **Strategist**（平台策略与内容方向），再 **Planner**（排期与选题）；未配置 AI 或失败时使用本地兜底（按平台匹配题库、尽量避免重复）。
- **选题库 / 内容生产 / 社群**：读取 AI 排期结果；内容生产单独 AI 写稿。

生成计划时会依次请求策略与排期，耗时比原来更长，属正常现象。
